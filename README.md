# Paradise Nursery Shopping Cart

Paradise Nursery is a React and Redux shopping cart application for an online plant shop. Users can browse houseplants, add plants to a cart, update quantities, remove items, and view dynamic cart totals.

## Project Features

- Landing page with the Paradise Nursery company name and a Get Started button.
- About Us section describing the company.
- Product listing page with six unique houseplants grouped into three categories.
- Product cards with thumbnail images, names, prices, and Add to Cart buttons.
- Add to Cart buttons become disabled after a plant is added.
- Cart icon displays the total number of cart items dynamically.
- Shopping cart page displays each item, unit price, quantity controls, item totals, and the total cart amount.
- Checkout button displays a Coming Soon message.
- Continue Shopping button returns to the product listing page.
